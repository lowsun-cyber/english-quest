# 🎮 English Quest

**Английский для младших школьников в пиксельном блочном мире.** Игровой тренажёр по темам учебника «Английский в фокусе» (Spotlight) для 2–4 классов: карта уровней, герои-помощники, чёткая озвучка медленным мужским голосом, произношение с распознаванием речи и режим для родителей и репетиторов.

**▶️ Открыть: [lowsun-cyber.github.io/english-quest](https://lowsun-cyber.github.io/english-quest/)** · 📖 [Гайд How to](https://lowsun-cyber.github.io/english-quest/how-to.html)

Работает в браузере на планшете, телефоне и компьютере, устанавливается как приложение и занимается без интернета. Интерфейс на русском, английский — только в самих заданиях.

## Что внутри

**Для ребят**
- 🗺️ **Карта мира** — три региона по учебникам: Зелёная долина (2 класс), Город мастеров (3 класс), Большая экспедиция (4 класс); 54 темы по Spotlight и ФРП: 241, 410 и 609 слов накопительно (цель ФРП — 200, 350 и 500), после каждых 4 тем — проверка на 💎 или 🏆.
- 🗝️ **Квесты и редкость** — каждое упражнение темы — квест: обычный, редкий, эпический (по типу задания из карты программы); редкие и эпические открываются по мастерству (80% в обычных, затем в редких), приз виден заранее и выдаётся один раз; проверки — легендарные «боссы»; сундук достижений.
- 🧩 **Задания по карте программы** — «Что на картинке?» (2 класс), «Вставь слово» (с 3 класса), «Собери предложение» (4 класс); учёт грамматики по навыкам G2–G4.
- 📖 **Словарь** — около 1000 слов: поиск по-английски и по-русски, перевод фразы по словам.
- 🧩 **8 упражнений** — карточки, слова, «Слушай», «Пара», «Напиши», грамматика, чтение и «Говори».
- 🎤 **«Говори»** — ребёнок произносит фразу, приложение подсвечивает слова, которые получились, и даёт послушать трудные.
- ⛏️ **Секретный регион «Шахты»** — на карте под туманом со счётчиком «Редких квестов: N из 10»; открывается после 10 редких квестов, внутри — 3 эпических места и легендарный босс со смешанными вопросами по пройденным темам, награда — кристаллы для будущей клиники (данные в `SECRET_REGIONS`).
- ⚔️ **Квест-реванш** — когда в «Моих ошибках» 5 трудных слов и вопросов, на карте появляется реванш на самые трудные (до 7) в формате на ступень проще; кнопка «Продолжить» ведёт сначала на повторение, потом на незакрытое в текущей теме.
- 🔁 **«Мои ошибки»** — неверные ответы возвращаются для повторения через растущие промежутки, пока не будут выучены. У каждой ошибки — тип (не узнал, перепутал с похожим, написание, форма, смысл текста), а после неверного ответа — короткий разбор: что значит выбранное и что было нужно.
- 🏅 **Награды** — опыт и 60 уровней, 12 званий (по 4 в каждом регионе — за темы и проверки, а не за опыт), золото, коллекция слов, цель дня и серия дней с 🧊 заморозками.
- 🦸 **Команда героев** — пять рисованных героев (`assets/heroes/`, у каждого 4 эмоции: рад, думает, подсказывает, хвалит); любого можно выбрать своим героем-аватаром. Dr. Harlow и его друзья подсказывают и хвалят по-русски и по-английски (голоса синтезированы заранее и записаны в файлы).

**Для родителей и репетиторов**
- 📊 **Панель взрослых** под PIN-кодом — минуты по дням, процент верных ответов, темы, трудные слова, мастерство слов и грамматических навыков (с учётом давности ответов), типы ошибок, опоры слабых навыков, короткий отчёт для мессенджера.
- 📬 **Домашние задания** — ссылкой: ребёнок открывает её и видит, что нужно сделать и к какому сроку.
- 🖨️ **Печатный лист «Трудные слова»** — из ошибок конкретного ученика.
- 👨‍👩‍👧 **Несколько учеников** на одном устройстве, у каждого свой прогресс и свой герой; при запуске — экран «Кто играет?» без PIN.
- 💾 **Перенос и резервная копия** прогресса файлом или кодом — без регистрации.

**Сервер учителя** (готов к установке)
- ☁️ Синхронизация прогресса между устройствами ученика — изменения с разных устройств аккуратно объединяются.
- 🛠️ Админ-панель (`/admin/`): учётные записи учеников, репетиторов и администраторов, прогресс и домашние задания, подключение устройств, выгрузка полного отчёта по ученику в PDF.
- Закрытые аккаунты без публичной регистрации; об ученике хранятся только имя и аватар.

## Как устроено

- Статический сайт на чистом HTML, CSS и JavaScript (ES-модули), без сборки и зависимостей.
- PWA: service worker хранит приложение и озвучку на устройстве.
- Озвучка — заранее записанные файлы (621 шт.); голос устройства — только запасной вариант.
- Распознавание речи — встроенное в браузер (Web Speech API): лучше всего в Chrome, Edge и Safari.
- Прогресс хранится на устройстве (localStorage + IndexedDB).
- Сервер — PHP 8.1+ и MySQL/PostgreSQL, без фреймворков: работает на обычном хостинге, переезжает на VDS без изменений. Установка — [server/README.md](server/README.md).

```
index.html, how-to.html               страницы приложения
admin/                                  админ-панель
js/                                     модули приложения
content.js                              уроки, слова, фразы, герои
tts_cache/, tts_*.json                  озвучка
server/                                 сервер учителя (PHP)
tests/                                  автотесты
tools/                                  генерация и импорт озвучки
```

## Запуск и проверка

```bash
python3 -m http.server 8000     # открыть http://localhost:8000
```

```bash
node tests/speech.mjs   # сравнение речи для «Говори»
node tests/merge.mjs    # объединение прогресса с разных устройств
node tests/curriculum.mjs  # разметка уроков по карте программы (темы, навыки G2–G4, граф навыков)
node tests/mastery.mjs  # типы ошибок, мастерство, квесты (редкость, замки) и достижения
node tests/api.mjs      # сервер учителя (нужен PHP 8.1+)
node tests/smoke.mjs    # всё приложение в headless Chrome
```

При каждой отправке в `main` GitHub Actions запускает все тесты и публикует сайт на GitHub Pages, только если они прошли.

## Приватность

Без сервера никакие данные с устройства не уходят. На сервере учителя хранятся только имя (или прозвище) и аватар ученика и его учебный прогресс — без фамилий, почты и дат рождения.
