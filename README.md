# 🎮 English Quest

**Английский для младших школьников в стиле Minecraft × Roblox.** Игровой тренажёр по темам учебника «Английский в фокусе» (Spotlight) для 2–4 классов: карта уровней, герои-помощники, озвучка носителем, произношение с распознаванием речи и режим для родителей и репетиторов.

**▶️ Открыть: [lowsun-cyber.github.io/english-quest](https://lowsun-cyber.github.io/english-quest/)** · 📖 [Гайд How to](https://lowsun-cyber.github.io/english-quest/how-to.html)

Работает в браузере на планшете, телефоне и компьютере, устанавливается как приложение и занимается без интернета. Интерфейс на русском, английский — только в самих заданиях.

---

## Что внутри

**Для ребят**
- 🗺️ **Карта уровней** — 43 темы для 2, 3 и 4 класса (около 450 слов; 2 класс — 18 тем и 241 слово, 3 класс — 17 тем и 410 слов накопительно, как требует ФРП), после каждых 4 тем — проверка на 💎 или 🏆.
- 📖 **Словарь** — около 1000 слов: поиск по-английски и по-русски, перевод фразы по словам.
- 🧩 **8 упражнений** — карточки, слова, «Слушай», «Пара», «Напиши», грамматика, чтение и «Говори».
- 🎤 **«Говори»** — ребёнок произносит фразу, приложение подсвечивает слова, которые получились, и даёт послушать трудные.
- 🔁 **«Мои ошибки»** — неверные ответы возвращаются для повторения через растущие промежутки, пока не будут выучены.
- 🏅 **Награды** — опыт, уровни и звания, золото, коллекция слов, цель дня и серия дней с 🧊 заморозками.
- 🦸 **Команда героев** — Dr. Harlow и его друзья подсказывают и хвалят живыми голосами на русском и английском.

**Для родителей и репетиторов**
- 📊 **Панель взрослых** под PIN-кодом — минуты по дням, процент верных ответов, темы, трудные слова, короткий отчёт для мессенджера.
- 📬 **Домашние задания** — ссылкой: ребёнок открывает её и видит, что нужно сделать и к какому сроку.
- 🖨️ **Печатный лист «Трудные слова»** — из ошибок конкретного ученика.
- 👨‍👩‍👧 **Несколько учеников** на одном устройстве, у каждого свой прогресс.
- 💾 **Перенос и резервная копия** прогресса файлом или кодом — без регистрации.

**Сервер учителя** (готов к установке)
- ☁️ Синхронизация прогресса между устройствами ученика — изменения с разных устройств аккуратно объединяются.
- 🛠️ Админ-панель (`/admin/`): учётные записи учеников, репетиторов и администраторов, прогресс и домашние задания, подключение устройств, выгрузка полного отчёта по ученику в PDF.
- Закрытые аккаунты без публичной регистрации; об ученике хранятся только имя и аватар.

## Как устроено

- Статический сайт на чистом HTML, CSS и JavaScript (ES-модули), без сборки и зависимостей.
- PWA: service worker хранит приложение и озвучку на устройстве.
- Озвучка — заранее записанные файлы (621 шт.); голос устройства — только запасной вариант.
- Распознавание речи — встроенное в браузер (Web Speech API): лучше всего в Chrome, Edge и Safari.
- Прогресс хранится на устройстве (localStorage + IndexedDB).
- Сервер — PHP 8.1+ и MySQL/PostgreSQL, без фреймворков: работает на обычном хостинге, переезжает на VDS без изменений. Установка — [server/README.md](server/README.md).

```
index.html, how-to.html               страницы приложения
admin/                                  админ-панель
js/                                     модули приложения
content.js                              уроки, слова, фразы, герои
tts_cache/, tts_*.json                  озвучка
server/                                 сервер учителя (PHP)
tests/                                  автотесты
tools/                                  генерация и импорт озвучки
```

## Запуск и проверка

```bash
python3 -m http.server 8000     # открыть http://localhost:8000
```

```bash
node tests/speech.mjs   # сравнение речи для «Говори»
node tests/merge.mjs    # объединение прогресса с разных устройств
node tests/curriculum.mjs  # разметка уроков по карте программы (темы, навыки G2–G4)
node tests/api.mjs      # сервер учителя (нужен PHP 8.1+)
node tests/smoke.mjs    # всё приложение в headless Chrome
```

При каждой отправке в `main` GitHub Actions запускает все тесты и публикует сайт на GitHub Pages, только если они прошли.

## Приватность

Без сервера никакие данные с устройства не уходят. На сервере учителя хранятся только имя (или прозвище) и аватар ученика и его учебный прогресс — без фамилий, почты и дат рождения.
