# Сервер English Quest

Хранит прогресс учеников и даёт учителю кабинет (`teacher.html`). Обычный PHP 8.1+ и MySQL — работает на виртуальном хостинге (сейчас Спринтхост) и без изменений переедет на VDS.

```
server/
  public/       ← веб-папка поддомена: index.php и .htaccess
  src/app.php   ← весь код API
  bin/setup.php ← установка и служебные команды (по SSH)
  config.php    ← пароли и настройки (создаётся из config.example.php, в git не попадает)
```

## Установка на Спринтхост (один раз)

1. **База.** Панель → «Базы данных MySQL» → создать базу. Запишите имя базы, пользователя и пароль.
2. **Поддомен.** Панель → «Сайты» → добавить поддомен `quest-api.logiqa.ru`. В его настройках выбрать **PHP 8.3** (подойдёт любая от 8.1).
3. **HTTPS.** Панель → SSL → бесплатный сертификат Let's Encrypt для `quest-api.logiqa.ru`.
4. **Файлы.** Загрузить по SFTP так, чтобы в папке сайта поддомена лежало:
   ```
   <папка поддомена>/public_html/   ← содержимое server/public (index.php, .htaccess)
   <папка поддомена>/src/           ← server/src
   <папка поддомена>/bin/           ← server/bin
   <папка поддомена>/config.php     ← из config.example.php, со своими значениями
   ```
   Главное: `src`, `bin` и `config.php` лежат **рядом** с `public_html`, а не внутри — так их не открыть из браузера.
5. **Настройки.** В `config.php` вписать базу (`mysql:host=localhost;dbname=…;charset=utf8mb4`), пользователя, пароль и случайную строку в `secret`.
6. **Первый запуск** (по SSH, в папке поддомена):
   ```bash
   php -v                        # должна быть 8.1+; если нет — php8.3 вместо php
   php bin/setup.php init "Мои ученики" "Ваше имя"
   ```
   Команда создаст таблицы, организацию и владельца и покажет **код входа** в кабинет учителя.
7. **Проверка:** `https://quest-api.logiqa.ru/` должен ответить `{"app":"english-quest","ok":true}`.
8. После этого в `js/config.js` указывается адрес сервера — и в приложении появляются «Сервер учителя» и «Кабинет учителя».

## Служебные команды

```bash
php bin/setup.php code    # новый код входа для владельца (если сменили устройство)
php bin/setup.php users   # список взрослых
```

## Резервная копия

Всё хранится в базе MySQL. В панели Спринтхоста включите ежедневные резервные копии базы или делайте выгрузку `mysqldump` по расписанию (cron).

## Переезд на VDS

Скопировать папку сервера и выгрузку базы (`mysqldump` → `mysql`), настроить nginx + PHP-FPM с корнем в `public/`, поменять `dsn` в `config.php`, перенаправить поддомен на новый адрес. Код менять не нужно. Можно перейти и на PostgreSQL: SQL написан переносимо, поменяется только `dsn`.

## Проверка на своём компьютере

```bash
node tests/api.mjs     # API на временной базе SQLite

node tests/smoke.mjs   # всё приложение в Chrome, включая синхронизацию
```
