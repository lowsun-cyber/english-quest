# docs/design-v2

Это графический стиль и концепция English Quest v2, перенесённые с холста «Dr. Harlow — эскизы» и из документа концепции.

С чего начинать:

1. `STYLE.md` — правила стиля, токены, герои, экраны, сцены. Его читать первым.
2. `CONCEPT.md` — полная концепция v2: решения владельца, карта мира, редкость, клиника, адаптивность, порядок работ и задание итерации 1.
3. `shots/*.png` — посмотреть, как выглядят эскизы.
4. `boards/*.html` — разметка эскизов: точные размеры, цвета, отступы. Эскизы открываются в браузере.
5. `heroes/*.svg` — рисунки героев. В задании итерации 1 они копируются в `assets/heroes/`.
6. `locations/*.svg` и `locations/index.json` — рисунки локаций для карты-пути. Копируются в `assets/locations/`.

Эскизы служат образцом, а не готовым кодом. Переносить в игру нужно стиль и структуру, через токены `style.css` и существующие компоненты.
