# English Quest v2: графический стиль

Этот файл описывает визуальный стиль v2 для разработки. Он дополняет `DESIGN.md` в корне и берёт верх там, где они расходятся. Эскизы с холста лежат рядом:

- `boards/*.html` — эскизы как страницы. Их можно открыть в браузере, интерактивные кликаются. Небольшой `dc-shim.js` нужен только для просмотра эскизов, в игру его не переносить.
- `shots/*.png` — снимки тех же эскизов. Сняты без сетевых шрифтов, поэтому шрифт на них запасной. Настоящие шрифты описаны ниже.
- `heroes/*.svg` — пять героев и по четыре эмоции у каждого, итого 25 файлов.
- `locations/*.svg` — рисунки-островки для каждой локации: 24 темы, 6 испытаний и 4 локации Шахт. Список с названиями лежит в `locations/index.json`.
- `CONCEPT.md` — полная концепция v2, экспорт от 11.10.2026.

## 1. Главное о стиле

- **Свой блочный мир.** Стиль описывается как собственный: «блочный мир», «игрушечные герои», «игровые карточки». Названия Roblox, Minecraft и Animal Hospital не встречаются нигде: в интерфейсе, тексте, коде, комментариях и именах файлов.
- **Выбран стиль Б, «игрушка».** Герои гладкие и игрушечные, с крупной головой, контуром 3 px и плоской заливкой без градиентов. Пиксельные спрайты (вариант В) не используются.
- **Сохраняется** всё из `DESIGN.md`: жёсткие тени со смещением, тёмный контур 3 px, кнопки с нажатием, палитра блоков, два шрифта.

## 3. Шрифты

- **Press Start 2P** (`--font-pixel`) — только для логотипа, коротких заголовков и бейджей длиной до 4 слов, например «КТО ИГРАЕТ?» или «L14».
- **Baloo 2** с начертаниями 500, 700 и 800 (`--font-body`) — для всего остального. На эскизах заголовки карточек 800, текст 600–700.
- Английский учебный текст всегда самый крупный на экране: не меньше 20 px, а слово для чтения вслух — 24 px и больше.

## 6. Локация как сцена

Это главное правило v2: локация рисуется как одно место, а каждый квест привязан к предмету в нём.

- **Сцена** — SVG в рамке с контуром 3 px и тенью `4px 4px 0`. Табличка с названием стоит в левом верхнем углу: регион мелко капсом цветом региона, локация крупно с жирностью 800.
- **Метка квеста** — круг 50 px с контуром 4 px и заливкой цвета редкости. В метке номер, если квест открыт, ★, если пройден, или замок, если закрыт. У закрытой метки серая заливка `--locked` и рамка цвета редкости. Выбранная метка получает двойное кольцо: `0 0 0 4px var(--surface), 0 0 0 7px var(--ink)`.
- **Карточка квеста** — таблетка редкости и место (например, «Кристальная жила»), название крупно, одна фраза о задании, приз. Кнопка зависит от состояния: «Играть» (`--grass`), «Пройдено ★★★ · ещё раз» или строка с замком и условием открытия.
- **Прогресс локации** — полоска и подпись «1 из 6». Внизу легенда цветов редкости: цвет всегда подписан словом.
- **Данные:** у метки есть координаты `x`, `y` в системе координат сцены, редкость, статус (`open` / `done` / `locked`), место, название, описание, приз и текст условия. Структура данных есть в `boards/40-scene-mines.html`, массив `Q`. Сцена и метки задаются данными темы, а пакет локации описан в `CONCEPT.md`, раздел «Карта мира» → «Новые локации».

## 7. Главная: карта-путь

Эскиз `34-screen-map-path`, атлас рисунков `41-atlas`. Главная страница — это дорога через регион текущего класса, а не сетка плиток.

- **Сверху вниз:**
  - шапка игрока;
  - полоска пройденного региона;
  - табличка региона («РЕГИОН · 3 КЛАСС», название, «3 из 8»);
  - дорога через 8 тем и 2 испытания (после 4-й и 8-й темы);
  - внизу туман и замок следующего региона;
  - нижнее меню.
- **Тема на дороге** — островок с рисунком локации из `locations/` (≈ 170×110). Метка темы 52 px стоит у переднего края островка, под ней табличка с названием локации. Островки чередуются слева и справа: центры по x = 110 и 280 при ширине 390, шаг по высоте 160 px.
- **Испытание** — островок по центру. Метка в форме щита, рамка `--gold-2`.
- **Дорога** — плавная кривая между метками: тёмный контур 34 px, полотно 27 px, пунктир по центру. Пройденный отрезок песочный `#f3dcb5` с пунктиром `#c0742c`, дорога впереди серая `#d6dcd8`.
- **Состояния:**
  - пройдено — яркий рисунок, зелёная метка со ★;
  - текущая — белая метка с номером и жёлтым кольцом; рядом стоит герой игрока с табличкой «Ты здесь»;
  - закрыто — рисунок обесцвечен (saturate ≈ 0.12), серая метка с замком.
- **Нажатие на метку** открывает карточку рядом с ней: «ЛОКАЦИЯ N ИЗ 8», название, тема Spotlight, прогресс квестов. Кнопка зависит от состояния: «Войти в локацию», «Повторить» или строка с условием.
- **При открытии** экран прокручивается к текущей теме.
- **Данные.** У каждой темы есть файл рисунка, название локации, порядок и статус. Новые локации из пакетов (`CONCEPT.md`, «Новые локации») приносят свой рисунок-островок того же формата.

## 8. Предметы на героях

Эскизы `20-…24-items-*`. На героя надеваются предметы в пять слотов: голова, в руку, спина, спутник, аура. Редкость предмета равна редкости квеста, а рамка карточки предмета — цвету редкости. Таблица предметов по героям приведена в `CONCEPT.md`, раздел «Достижения — предметы для героя». Рисунки и названия предметов свои, чужие игровые предметы не копируются.

## 9. Доступность и движение

Всё из `DESIGN.md` остаётся в силе:

- контраст AA в обеих темах;
- у каждого нового компонента есть тёмная тема;
- зона нажатия не меньше 44 px, для меток и ответов 48 px и больше;
- цвет не единственный признак: у редкости есть подпись, у состояния есть значок;
- учитывается `prefers-reduced-motion`;
- обратная связь короче 400 мс.

Для меток в сцене и на карте-пути нужен понятный `aria-label`, например «Кристальная жила: Кристаллы прошлого» или «Ворота Глубокого забоя: Хранитель глубин, закрыто».
