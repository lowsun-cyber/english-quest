# Посылки от Dr. Harlow — AI-пакеты (итерация 5)

Раз в неделю взрослый готовит ученику 1–3 особых квеста под его пробелы. Модель вызывает только взрослый: у ребёнка вызовов AI нет, каждое задание проверяет человек.

## Как подготовить посылку

1. **Выгрузка.** В админ-панели, на странице ученика, раздел «Посылка от Dr. Harlow» → «🤖 Скопировать задание для AI». То же есть в панели репетитора на устройстве. В буфер попадает шаблон задания и прогресс ученика без имени:
   - пробелы по кодам ошибок;
   - навыки грамматики и неверные варианты, которые ребёнок выбирал;
   - трудные слова и с чем ребёнок их путает;
   - знакомые слова.
2. **Модель.** Вставить текст в Claude и, по желанию, в Perplexity — сверить ответы. Модель отвечает одним JSON посылки.
3. **Проверка человеком.** Прочитать каждое задание:
   - ответ однозначный;
   - объяснения к неверным вариантам верные и понятные ребёнку;
   - нет личных данных.

   Формат проверяется автоматически: в админ-панели кнопкой «Проверить» или так:
   ```
   node tools/parcel.mjs посылка.json
   ```
4. **Отправка.**
   - Ученику на сервере — «📦 Отправить ученику» в админ-панели. Посылка придёт при следующей синхронизации устройства.
   - Ученику без сервера — «Проверить и добавить» в панели репетитора на его устройстве.
5. **У ребёнка** над картой появляется «📦 Посылка от Dr. Harlow!»:
   - письмо Dr. Harlow;
   - приз за всю посылку виден заранее;
   - особые квесты: каждый на 80%, за первое прохождение +40 XP и +20 🪙.

   За всю посылку — уникальный приз в «Сундуке достижений» с именем игрока и датой. Ошибки особых квестов идут в карту пробелов, но не в «Мои ошибки»: у этих заданий нет темы в учебнике.

## Формат

Образец — [`example-parcel.json`](example-parcel.json). Шаблон задания для модели — константа `AI_PROMPT` в `js/aipack.js`, проверка — `validateParcel` там же.

| Поле | Что это |
| --- | --- |
| `format` | всегда `eq-parcel/1` |
| `id` | латиница, цифры, дефисы, 3–60 знаков; та же посылка с тем же `id` заменяет прежнюю |
| `student` | код ученика из выгрузки. Необязательно, но если указан, посылку не примут для другого ученика |
| `title`, `note` | название и письмо Dr. Harlow (до 400 знаков), по-русски |
| `reward` | `title` и `emoji` уникального приза: название говорит, чему ребёнок научился |
| `quests` | 1–3 квеста: `id`, `title`, `emoji`, `focus` (коды ошибок: W1, B1, L1…), `words` и `grammar` |

Правила для квеста:
- **`words`** — не меньше 4 слов (`en`, `ru`, `emoji`): из них собираются вопросы «как по-английски?» и «послушай и выбери».
- **`grammar`** — вопросы с `___`, 2–4 варианта, ответ `a`, подсказка `hint`. У каждого неверного варианта — объяснение в `why`, как в учебных темах.
- **Размер:** заданий в квесте от 4 до 15, вся посылка — до 60 КБ.

## Хранение и доставка

- Посылки лежат в прогрессе ученика (`parcels`), результаты квестов — в `quests` под ключами `sp:посылка:квест`.
- При объединении прогресса с разных устройств посылки не теряются.
- Отозванная в админ-панели посылка исчезает у ученика при синхронизации.
- В прогрессе хранится до 20 посылок, самые старые выполненные уходят.

## Озвучка

Новые слова из посылки звучат голосом устройства. Если нужна запись тем же голосом, что в учебных темах, её делают тем же инструментом (`tools/gen-voices.mjs`) вместе с посылкой. Ключ API хранится только у владельца.
