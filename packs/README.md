# Пакеты локаций

Пакет добавляет в игру новое без правки её кода. Пакеты двух видов:

- **новая локация** (`"type": "location"`) — тема за пределами Spotlight или идея из другого источника, например «Космос» в Большой экспедиции. Такая тема встаёт в конец региона своего класса, поэтому уже пройденные темы и проверки не сдвигаются;
- **новые квесты в старой локации** (`"type": "quests"`) — больше практики, новый тип задания или усложнение, например коробка с игрушками и квест на this / these в «Come in and Play!». Прогресс по уже пройденным квестам темы сохраняется.

У новой темы и у ещё не начатого нового квеста 14 дней после подключения (`addedAt`) стоит метка **«Новое»**.

Пакет готовит владелец вместе с Claude по шаблону ниже. Сюда же Claude ссылается в задании.

## Как подключить

1. Положить файл `packs/<id>.json`. Имя файла совпадает с `id`.
2. Проверить его командой `node tools/packs.mjs`. Неподключённые пакеты проверяются без озвучки.
3. Озвучить:
   - `node tools/voice-todo.mjs ~/Downloads/quest-voice` — задание на озвучку, фразы пакетов в нём уже есть;
   - затем `node tools/import-voices.mjs ~/Downloads/quest-voice` — подключить готовые записи.
4. Добавить `id` в `packs/index.json` (список подключённых) и снова запустить `node tools/packs.mjs`. Скрипт строго проверит пакет, в том числе что всё озвучено, и соберёт `packs.js` — его читает сайт.
5. Тесты (`node tests/packs.mjs` и остальные), коммит, PR. К ученикам пакет попадает после слияния, то есть после подтверждения владельца.

Загрузка через админ-панель будет в итерации 5 вместе с AI-пакетами. Сейчас пакеты подключаются коммитом.

## Что проверяется

- `id` состоит из латиницы, цифр и дефиса, имя файла совпадает с `id`; `addedAt` — дата `ГГГГ-ММ-ДД`; `layer` — `base`, `frp` или `ext`.
- **Новая тема:**
  - класс 2–4 и гид из команды героев;
  - не меньше 6 слов, среди них хотя бы 4 разные картинки;
  - 2 фразы для «Говори», 2 вопроса грамматики и текст для чтения.
- **Квесты:**
  - `kind` — одно из упражнений: `cards`, `vocab`, `listen`, `match`, `spell`, `grammar`, `reading`, `picture`, `speak`;
  - хватает материала: для слов — 4 слова с разными картинками, для грамматики — 2 вопроса.
- **Грамматика:** в `q` есть `___`, ответ `a` есть среди `options`, коды навыков `skill` существуют (G2-01…G4-12 из карты программы). У каждого неверного варианта — своё объяснение в `why` (`{"These": "These — для многих предметов, а мишка один."}`): его показывает гид, когда ребёнок выбрал этот вариант.
- **Сцена:** метки лежат внутри картинки и ведут на квесты пакета, файл картинки существует.
- **Подключённые пакеты:** всё, что звучит, озвучено — слова, фразы, предложения грамматики, тексты и вступление Dr. Harlow к новой теме.

## Шаблон

Готовые примеры — `example-g3-toybox.json` (квесты) и `example-g4-space.json` (локация). Они не подключены, пока не озвучены.

```json
{
  "id": "g3-toybox",
  "type": "quests",
  "title": "Коробка с игрушками: this / these",
  "addedAt": "2026-10-11",
  "layer": "base",
  "lessonId": "g3-toys3",
  "quests": [
    {
      "id": "toybox-this-these",
      "kind": "grammar",
      "title": "Коробка с игрушками",
      "emoji": "🧸",
      "rarity": "rare",
      "words": [],
      "grammar": [
        { "skill": "G3-04", "q": "___ is my teddy bear.", "a": "This", "hint": "Один предмет рядом — this.", "options": ["This", "These", "Those"], "why": {"These": "These — для многих предметов, а мишка один.", "Those": "Those — для многих и далеко, а мишка один и рядом."} }
      ]
    }
  ],
  "scene": null,
  "patient": null,
  "reward": null
}
```

Поля квеста:
- **`words`, `grammar`, `reading`, `pics`, `phrases`** — свои слова, вопросы, текст, картинки и фразы. Если поле не указано, берётся из темы.
- **`rarity`** — `common`, `rare` или `epic`. По умолчанию — по упражнению, как у остальных квестов. Открытие идёт по тем же правилам мастерства, что у остальных квестов.

Поля новой темы (`"type": "location"`) — в объекте `lesson`, как у тем в `content.js`:
- `grade`, `guide`, `module`, `topics`, `cefr`;
- `title`, `subtitle`, `intro`;
- `words`, `phrases`, `grammar`, `reading`, `pics`.

Свои квесты у новой темы тоже можно задать — в `quests`.

Поля на будущее:
- **`scene`** — `image`, `width`, `height`, `markers: [{ "quest", "x", "y" }]`. Сцена локации с метками на предметах; рисоваться будет, когда появятся картинки сцен.
- **`patient`, `reward`** — пациент и награда для клиники, итерация 4.
